# 機能一覧

画面は 3 つ。`ScrHome`（3 タブ）、`ScrUser`（利用者の詳細）、`ScrReq`（申請の詳細）。

## 共通（全画面）

| 機能 | 説明 |
|---|---|
| **読み直す** | SharePoint からマスタを読み直す。編集中の内容があるときは押しても読み直さず、申請か取り消しを促す |
| **元に戻す / やり直す** | **表示中の画面（タブ）の変更だけ**を対象にした取り消し。別画面のものには触らない |
| ログイン者の表示 | ヘッダ右端に氏名。グローバルIDは出さない |
| 差し戻しの知らせ | 自分の申請が差し戻されていると、起動時に通知＋画面上部にバー。押すと差し戻しに絞った申請履歴へ |

ボタンの位置は全画面で同じ（ヘッダ右、利用者名の左）。

### 元に戻す / やり直すの範囲

| 画面 | 戻す対象 |
|---|---|
| 組織マスタ タブ | 今の組織区分1 の「組織区分1 の設定」と「組織区分2」 |
| ユーザマスタ タブ | 今の組織区分1 の権限・新規利用者・利用者の基本情報 |
| 利用者の画面 | **その利用者の**権限・登録・基本情報 |

履歴は画面に入ったとき、組織区分1 を切り替えたとき、読み直したとき、申請したときに作り直す。

> **キーボードショートカットは無い。** キャンバスアプリにキーイベントを受け取る仕組みが無く、
> PCF も使えないため。ボタンのみ。

## 組織マスタ タブ

| 機能 | 説明 |
|---|---|
| 組織区分1 の選択 | 自分が所属する組織区分1 のドロップダウン。1 つだけなら固定表示 |
| 組織区分1 の情報 | コード・日本語名称・英語名称を表示（変更不可） |
| 組織区分2 の一覧 | コード・日本語名称・英語名称・表示順・多段階承認要否 3 種・削除 |
| 名称の変更 | 日本語名称・英語名称を直接編集 |
| 表示順の入れ替え | ▲▼ で並べ替え |
| **多段階承認の要否** | 外部接続 / 無線LAN / クラウド のセルをクリックで 要 ↔ 不要 |
| 新規登録 | コードは自動採番（`A` + 組織区分1 コードの下 2 桁 + 連番 2 桁） |
| 削除 | 削除対象の行に取り消し線 |
| 申請 | かご（申請明細）に溜めてから一括で申請 |

## ユーザマスタ タブ

行が組織区分2、列が利用者（10 人ずつページング）のマトリックス。

| 機能 | 説明 |
|---|---|
| 権限種別の切り替え | 事業場ITセキュリティ責任者 / 適合化 / 外部接続 / 無線LAN / クラウド / 情報セキュリティ |
| 全体 | 「全体(組織区分2すべて)」の行。チェックすると範囲が全体になる |
| 個別 | 組織区分2 ごとのセルをクリックで付与・削除 |
| 対象外 | その権限種別の多段階承認が「不要」の組織区分2 は `―` で、設定できない |
| 氏名クリック | その利用者の詳細画面へ |
| 新規登録 | 利用者の新規登録画面へ |

## 利用者の画面（`ScrUser`）

| 機能 | 説明 |
|---|---|
| **AD からの引き当て** | 氏名またはメールアドレスで検索（🔍）。Entra ID から氏名・部署・オブジェクトIDを取得 |
| 候補の選択 | 複数見つかったら `氏名（メールアドレス）` のドロップダウンから選ぶ |
| 氏名・メール・部署 | **入力不可。** AD の値だけが入る |
| グローバルID | 手入力。新規のときのみ。数字 7 桁 または 英字 1 桁 + 数字 6 桁 |
| 所属組織区分1 | 新規は選択。既存はタブで切り替え |
| 権限種別ごとの範囲 | 権限なし / 全体 / 個別（組織区分2 を選ぶ） |
| **ユーザを削除** | **申請明細（かご）に入れる。** 他の変更と同じく「申請」を押すまで確定しない |
| **削除をやめる** | かごに入れたあとは「削除をやめる」に変わる。かごの一覧から外しても取り消せる |
| **削除を取り消す** | 申請済みなら「削除を取り消す」。押すと申請を取り下げる |
| 削除中の制限 | かごに入れた時点で権限は編集できない。他の変更が既にある利用者は削除できない |

## 申請履歴 タブ

| 機能 | 説明 |
|---|---|
| 種別の絞り込み | すべて / 組織マスタ変更 / ユーザ・権限申請 |
| 状態の絞り込み | すべて / 申請済み / 確認中 / 完了 / 差し戻し / 取り下げ |
| 一覧 | 申請日時・番号・種別・組織区分1・対象・申請者・明細件数・状態 |
| 表示範囲 | 管理者は全組織区分1、それ以外は自分の組織区分1 と自分が出した申請 |
| 行クリック | 申請の詳細へ |

## 申請の詳細（`ScrReq`）

| 機能 | 説明 |
|---|---|
| ヘッダ | 申請番号・種別・対象・申請者・日時・状態・明細件数・差し戻しの理由 |
| 明細の一覧 | 組織マスタの変更 / ユーザマスタの変更 の 2 タブ。変更内容を人が読める文で表示 |
| 明細から遷移 | 「開く」でその対象のマスタ画面へ。**参照のみ**（変更不可）で、この申請での変更内容を上部に表示 |
| 確認中にする | 状態を「確認中」へ |
| **完了にする** | **ここで初めてマスタへ反映される。取り消せない** |
| 差し戻す | 理由を付けて差し戻す。何も反映しない |
| 取り下げる | 申請者が取り下げる。何も反映しない |
| **内容を修正して再申請** | 差し戻された自分の申請を読み戻して編集し直す（下記） |

### 再申請

差し戻された自分の申請でのみ表示される。押すと申請の中身を編集中の状態に読み戻し、
マスタの画面へ移る。修正して申請すると**新しい申請番号**になる。

**参照先が動いていたら再申請させない。** 次のどちらかに当たると、理由つきで新規申請を促す。

- 申請したあとに、その申請が触る組織区分2・利用者・権限が変わっている
- 同じ対象に別の申請（申請済み・確認中）が出ている

## 変更の見せ方

編集中の変更と、申請中の変更を、同じ規則で見せる。

| 見た目 | 意味 |
|---|---|
| **・（名前の左）＋ 赤字** | 変更がある。タブ・組織区分1・組織区分2 のコード・権限種別・利用者名に付く |
| **赤字（セル単体）** | そのセルを変えた。名称・表示順・多段階承認の要否 |
| **取り消し線** | 削除対象。組織区分2 の行、利用者名 |
| **薄いピンクの網かけ** | 対応が要る。下記 |
| 申請中のバー | 未反映の申請がある件数。押すと申請履歴へ |

網かけが出る条件は 3 つ。

- 多段階承認が無効になり、**権限を外す必要がある**組織区分2 のチェック
- **承認できる人がいない**組織区分2（組織名の部分）
- 上の 2 つに当たる**権限種別**
