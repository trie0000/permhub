# 機能一覧

画面は 3 つ。`ScrHome`（3 タブ）、`ScrUser`（利用者の詳細）、`ScrReq`（申請の詳細）。

## 共通（全画面）

| 機能 | 説明 |
|---|---|
| **読み直す** | SharePoint からマスタを読み直す。編集中の内容があるときは押しても読み直さず、申請か取り消しを促す |
| **元に戻す / やり直す** | **表示中の画面（タブ）の変更だけ**を対象にした取り消し。別画面のものには触らない |
| ログイン者の表示 | ヘッダ右端に氏名。グローバルIDは出さない |
| 差し戻しの知らせ | 自分の申請が差し戻されていると、起動時に通知＋画面上部にバー。押すと差し戻しに絞った申請履歴へ |

ボタンの位置は全画面で同じ（ヘッダ右、利用者名の左）。

### 元に戻す / やり直すの範囲

| 画面 | 戻す対象 |
|---|---|
| 組織マスタ タブ | 今の組織区分1 の「組織区分1 の設定」と「組織区分2」 |
| ユーザマスタ タブ | 今の組織区分1 の権限・新規利用者・利用者の基本情報 |
| 利用者の画面 | **その利用者の**権限・登録・基本情報 |

履歴は画面に入ったとき、組織区分1 を切り替えたとき、読み直したとき、申請したときに作り直す。

> **キーボードショートカットは無い。** キャンバスアプリにキーイベントを受け取る仕組みが無く、
> PCF も使えないため。ボタンのみ。

## 組織マスタ タブ

| 機能 | 説明 |
|---|---|
| 組織区分1 の選択 | 自分が所属する組織区分1 のドロップダウン。1 つだけなら固定表示 |
| 組織区分1 の情報 | コード・日本語名称・英語名称を表示（変更不可） |
| 組織区分2 の一覧 | コード・日本語名称・英語名称・表示順・多段階承認要否 3 種・削除 |
| 名称の変更 | 日本語名称・英語名称を直接編集 |
| 表示順の入れ替え | ▲▼ で並べ替え |
| **多段階承認の要否** | 外部接続 / 無線LAN / クラウド のセルをクリックで 要 ↔ 不要 |
| 新規登録 | コードは自動採番（`A` + 組織区分1 コードの下 2 桁 + 連番 2 桁） |
| 削除 | 削除対象の行に取り消し線 |
| 申請 | かご（申請明細）に溜めてから一括で申請 |

## ユーザマスタ タブ

行が組織区分2、列が利用者（10 人ずつページング）のマトリックス。

| 機能 | 説明 |
|---|---|
| 権限種別の切り替え | 事業場ITセ責任者 / 適合化 / 外部接続 / 無線LAN / クラウド / 情報セキュリティ / **欧州窓口** |
| 全体 | 「全体(組織区分2すべて)」の行。チェックすると範囲が全体になる |
| 個別 | 組織区分2 ごとのセルをクリックで付与・削除 |
| **事業会社権限** | 外部接続 / 無線LAN / クラウド のみ。名前と全体の間に 正 / 副。既定は正、クリックで切替 |
| 対象外 | その権限種別の多段階承認が「不要」の組織区分2 は `―` で、設定できない |
| 氏名クリック | その利用者の詳細画面へ |
| 新規登録 | 利用者の新規登録画面へ |
| **CSV 出力** | 権限一覧を画面に出す。枠の中を選択してコピーし、UTF-8 で `.csv` として保存する（`Download()` が `data:` URI を受け付けないため） |

## 利用者の画面（`ScrUser`）

| 機能 | 説明 |
|---|---|
| **AD からの引き当て** | 氏名またはメールアドレスで検索（🔍）。Entra ID から氏名・部署・オブジェクトIDを取得 |
| 候補の選択 | 複数見つかったら `氏名（メールアドレス）` のドロップダウンから選ぶ |
| 氏名・メール・部署 | **入力不可。** AD の値だけが入る |
| グローバルID | 手入力。新規のときのみ。数字 7 桁 または 英字 1 桁 + 数字 6 桁 |
| 所属組織区分1 | 新規は選択。既存はタブで切り替え |
| 権限種別ごとの範囲 | 権限なし / 全体 / 個別（組織区分2 を選ぶ） |
| **事業会社権限** | 全体チェックの上に 正 / 副。外部接続 / 無線LAN / クラウド のみ |
| **ユーザを削除** | **申請明細（かご）に入れる。** 他の変更と同じく「申請」を押すまで確定しない |
| **削除をやめる** | かごに入れたあとは「削除をやめる」に変わる。かごの一覧から外しても取り消せる |
| **削除を取り消す** | 申請済みなら「削除を取り消す」。押すと申請を取り下げる |
| 削除中の制限 | かごに入れた時点で権限は編集できない。他の変更が既にある利用者は削除できない |

## 申請履歴 タブ

| 機能 | 説明 |
|---|---|
| 種別の絞り込み | すべて / 組織マスタ変更 / ユーザ・権限申請 |
| 状態の絞り込み | すべて / 申請済み / 確認中 / 完了 / 差し戻し / 取り下げ |
| 一覧 | 申請日時・番号・種別・組織区分1・対象・申請者・明細件数・状態 |
| 表示範囲 | 管理者は全組織区分1、それ以外は自分の組織区分1 と自分が出した申請 |
| 行クリック | 申請の詳細へ |

## 申請の詳細（`ScrReq`）

| 機能 | 説明 |
|---|---|
| ヘッダ | 申請番号・種別・対象・申請者・日時・状態・明細件数・差し戻しの理由 |
| 明細の一覧 | 組織マスタの変更 / ユーザマスタの変更 の 2 タブ。変更内容を人が読める文で表示 |
| 明細から遷移 | 「開く」でその対象のマスタ画面へ。**参照のみ**（変更不可）。申請の内容を読み込むので、**変更箇所が申請時と同じ色**で出る。かごに編集中の内容があるときは読み込まず警告 |
| 確認中にする | 状態を「確認中」へ |
| **完了にする** | **ここで初めてマスタへ反映される。取り消せない** |
| 差し戻す | 理由を付けて差し戻す。何も反映しない |
| 取り下げる | 申請者が取り下げる。何も反映しない |
| **内容を修正して再申請** | 差し戻された自分の申請を読み戻して編集し直す（下記） |

### 再申請

差し戻された自分の申請でのみ表示される。押すと申請の中身を編集中の状態に読み戻し、
マスタの画面へ移る。修正して申請すると**新しい申請番号**になる。

**参照先が動いていたら再申請させない。** 次のどちらかに当たると、理由つきで新規申請を促す。

- 申請したあとに、その申請が触る組織区分2・利用者・権限が変わっている
- 同じ対象に別の申請（申請済み・確認中）が出ている

## 管理タブ（管理者のみ）

ヘッダーの「管理」から入る。`PRM_Config` の管理者グループに入っている人だけに出る。

### CSV の取り込み

**ファイルは選べない。貼り付ける。** キャンバスアプリは添付ファイルの中身を読めないため。

| 種類 | 見出し |
|---|---|
| 組織の親子 | 組織区分１,組織区分１日本語名称,組織区分１英語名称,組織区分２,組織区分２日本語名称,組織区分２英語名称,適用開始日,適用終了日,最終更新日,最終更新者 |
| 組織マスタ | 組織区分コード,組織区分日本語名称,組織区分英語名称,区分,クラウド多段,外部接続多段,無線LAN多段,最終更新日,最終更新者 |
| ユーザマスタ | 組織区分１,組織区分２,ロール名,ユーザ名,メールアドレス,最終更新日,最終更新者 |

受け付ける見出しは画面に出る。1 行目を見出しとして読み、**表形式で確認してから**「取り込む」。

- **Excel から直接貼れる。** タブ区切りもカンマ区切りも通る
- **区切り文字は自動で決める。** 文字列にタブが 1 つでもあればタブ区切り、無ければカンマ区切り
- **値にカンマが入っていてもよい**（Excel から貼ればタブ区切りになるため）
- 前後を `"` で囲んだ値は外して読む。中の `""` は `"` に戻す
- 列数が合わない行があると取り込ませない
- **ロール名が対応表に無い行**、**マスタに無い組織コードを指す行**があっても取り込ませない。
  読み取った時点で件数と実例を赤字で出す（押す前に分かる）
- **親子 → 組織マスタ → ユーザマスタ の順。** 親子が無いと後の 2 つは置けない
- 値にタブは使えない

**組織区分コードは 8 桁の数字。** 先頭 1 桁で種別が決まり、続く 4 桁が組織区分1 を表す。

```
1 0031 000   組織区分1（先頭が 1、末尾 3 桁は必ず 000）
2 0031 001   組織区分2（先頭が 2、続く 4 桁は親の組織区分1 と同じ）
```

**親子 CSV が無くても、組織区分2 のコードから親を導ける。** 組織マスタの取り込みでは、
マスタに無い組織区分2 を作るとき `1` + 中 4 桁 + `000` を親にする。親の組織区分1 が
まだ無ければ、コードを名称にした行を先に作る（あとで親子 CSV を入れれば名称が入る）。

ユーザマスタでも、組織区分1 がマスタに無ければ同じ規則で導く。

**利用者のキーはメールアドレス。** CSV にグローバルIDが無いため。グローバルID 欄は空のまま入る。

同じ利用者・組織区分1・権限種別の行は、**組織区分2 をまとめて `PICK` にする**。

```
tanaka@example.com, B01, 【事業会社】外部接続_事業会社(主), 田中, A0101
tanaka@example.com, B01, 【事業会社】外部接続_事業会社(主), 田中, A0103
  → Org2Codes = ;A0101;A0103;   CompanyRole = PRIMARY
```

ロール名は `fRoleMap` で権限種別と事業会社権限に振り分ける。対応表に無い行は飛ばし、件数を通知に出す。

| CSV のロール名 | 権限種別 | 事業会社権限 |
|---|---|---|
| 【事業会社】事業場ITセキュリティ責任者 | SECMGR | — |
| 【事業会社】適合化_窓口担当 | CONFORM | — |
| 【事業会社】外部接続_事業会社(主/副) | EXTCONN | 正 / 副 |
| 【事業会社】無線LAN_事業会社(主/副) | WLAN | 正 / 副 |
| 【事業会社】クラウド_事業会社(主/副) | CLOUD | 正 / 副 |
| 【事業会社】クラウド_情報セキュリティ担当 | INFOSEC | — |
| クラウド_欧州窓口 | EUCLOUD | — |

### 登録データの一括クリア

マスタ 5 本と申請 2 本を消す。**設定（`PRM_Config`）は残る。**
「削除」と入力するまでボタンは押せない。取り消せない。

**消すとログイン者の紐付け（`AdObjectId`）も消える。** そのままだと画面が空で開くので、
取り込んだあとに 1 人へ `AdObjectId` を入れ直すこと。

## 変更の見せ方

編集中の変更と、申請中の変更を、同じ規則で見せる。

| 見た目 | 意味 |
|---|---|
| **・（名前の左）＋ 赤字** | 変更がある。タブ・組織区分1・組織区分2 のコード・権限種別・利用者名に付く |
| **赤字（セル単体）** | そのセルを変えた。名称・表示順・多段階承認の要否 |
| **取り消し線** | 削除対象。組織区分2 の行、利用者名 |
| **薄いピンクの網かけ** | 対応が要る。下記 |
| 申請中のバー | 未反映の申請がある件数。押すと申請履歴へ |

網かけが出る条件は 3 つ。

- 多段階承認が無効になり、**権限を外す必要がある**組織区分2 のチェック
- **承認できる人がいない**組織区分2（組織名の部分）
- 上の 2 つに当たる**権限種別**

**灰色**は別の意味で、未完了の申請に含まれていて触れないことを示す。押すと理由が出る。
